ChatGPT 额度菜单栏
==================

系统要求
- macOS 14 或更高版本
- 已安装并登录最新版 ChatGPT/Codex 桌面客户端

安装
1. 双击“安装.command”。
2. 如果 macOS 阻止首次运行，请右键该文件并选择“打开”。
3. 菜单栏出现类似“5h 65% ↻12:50 · 周 94% ↻9/6”的文字即安装成功。

卸载
- 双击“卸载.command”。

说明
- 显示的是 ChatGPT 桌面端提供的 Codex/Work 额度窗口，不是 OpenAI API 账单。
- 数据每分钟刷新，不读取浏览器 Cookie，不保存账号令牌。
- 本项目不是 OpenAI 官方产品，与 OpenAI 无隶属或赞助关系。
